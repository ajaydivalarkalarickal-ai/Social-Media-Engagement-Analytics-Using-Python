# Social Media Engagement Analytics Using Python

A data analytics project exploring social media engagement patterns using Python. The project demonstrates an end-to-end beginner-friendly analytics workflow covering data cleaning, transformation, exploratory data analysis, statistical analysis, and visualization.

## Project Objective

The goal is to analyze social media performance data and identify patterns across engagement metrics such as likes, comments, shares, impressions, watch time, followers, post characteristics, and sentiment.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Google Colab

## Analysis Workflow

1. Imported and inspected the dataset.
2. Reviewed data types, missing values, and duplicate records.
3. Cleaned and standardized data for analysis.
4. Used NumPy and Pandas for numerical and tabular analysis.
5. Performed exploratory data analysis and descriptive statistics.
6. Analyzed engagement across post type, category, country, sentiment, and other dimensions.
7. Created static and interactive visualizations to communicate findings.

## Key Areas Explored

- Likes, comments, shares, impressions, and watch time
- Engagement rate and follower metrics
- Post type and post category performance
- Country-level engagement patterns
- Sentiment distribution
- Correlation between numerical variables
- Audience and device characteristics

## Visualizations

The analysis uses multiple visualization techniques, including scatter plots, line charts, bar charts, histograms, box plots, count plots, violin plots, correlation heatmaps, and interactive Plotly charts.
